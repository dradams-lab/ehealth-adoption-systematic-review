# /data — Systematic Review Data Directory

This directory holds all records generated by and passing through the PRISMA 2020 screening process.

---

## Folder Structure

```
data/
├── raw/          ← Raw database export files (to be populated after formal searches)
├── screened/     ← Deduplicated, combined record list with T/A screening decisions
└── final/        ← Retained sources with full evidence extraction data
```

---
