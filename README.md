# E-Health Adoption Systematic Review

Workspace for PRISMA materials, screening exports, thematic coding, references, manuscript drafts, and notes.

## Current Manuscript

The current Overleaf article is in `manuscript/`.

- Root file: `manuscript/main.tex`
- Local bibliography for Overleaf compilation: `manuscript/references.bib`
- Project-level reference copy: `references/library.bib`

## Folder Map

- `prisma/`: PRISMA diagram source and review counts workbook.
- `data/raw/`: Database exports from PubMed, Scopus, IEEE, and supplementary sources.
- `data/screened/`: Deduplicated and screened records.
- `data/final/`: Included-study data and extraction exports.
- `analysis/`: Coding workbook and synthesis notes.
- `references/`: Project reference libraries and Zotero exports.
- `manuscript/`: Canonical LaTeX manuscript synced with Overleaf.
- `notes/`: Search strategy and screening logs.
