\section{Results}

\subsection{Systematic Review Findings}
The seed evidence base indicates that eHealth adoption is not determined by a single technical variable. Across systematic reviews, umbrella reviews, policy analyses, and public implementation reports, adoption determinants consistently cluster into four domains: user readiness, technical interoperability, institutional alignment, and organizational execution.

User readiness determinants include usability, workflow fit, trust, training, perceived usefulness, and user satisfaction. Technical determinants include information quality, system quality, semantic and syntactic interoperability, reliability, interface integration, and data completeness. Institutional determinants include regulatory incentives, national digital health strategy, privacy law, interoperability mandates, and information governance. Organizational determinants include leadership, implementation planning, stakeholder engagement, change management, vendor governance, and resource capacity.

\subsection{Synthesis}
The evidence supports the proposed model:

\begin{equation}
Adoption = f(U, T, I, O)
\end{equation}

The case comparison suggests that technical interoperability is necessary but insufficient. Adoption is strongest when technical architecture, institutional mandate, organizational execution, and user readiness converge. Conversely, cases with strong policy mandate but weaker user satisfaction or implementation governance demonstrate lower realized adoption value.
